# Website

- Dev server: `npm run dev`
- Build: `npm run build`

## Layout

- `public/` - data which will be copied to output directly
- `src/components/` - Astro components
- `src/content/blog/` - Blog articles
- `src/lib/` - library code (no JSX)
- `src/pages/` - the page structure
- `src/react/` - React components
